# GovBridge — Innovation Procurement Hub

GovBridge is a static, responsive front-end concept for a startup-friendly public procurement workflow. It is designed to demonstrate an end-to-end mechanism from government problem identification through startup discovery, evaluation, controlled pilots, evidence, milestone payments, validation and procurement/scale-up decisions.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy
Upload `index.html` to a GitHub Pages repository. No build step or external library is required.

## Included workflows
- Department, Startup and Evaluator perspectives
- Challenge marketplace with search/filtering and challenge creation
- Startup discovery directory
- Weighted evaluation rubric with validation
- Pilot/milestone tracking
- Payment readiness workflow
- Compliance and reusable templates
- Procurement pathway and decision record
- Audit/evidence timeline
- Reports and settings
- Responsive mobile layout

The sample data and interactions are browser-side demonstration data. Production deployment would connect the same UI flows to authenticated backend services, organisational approval systems, document storage, identity, payments and approved procurement/marketplace integrations.
